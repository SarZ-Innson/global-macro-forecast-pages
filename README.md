# 全球宏观预测市场 · 定时快照

这个公开仓库用于 GitHub Pages 展示经审核的 Polymarket 宏观事件、结果选项及历史概率。目前公开数据包含 31 个事件、225 个子市场；实际数量和截止时间以 `data/v1/index.json` 为准。事件和选项使用与私有采集仓库分离的公开 UUID，原始快照、审核记录、来源 ID 映射和密钥不进入这个仓库。

私有仓库约每两小时尝试刷新一次：先完成 Gamma 官方接口的分类普查，复用按事件 ID 保存的首次 Jev 判断及人工决定，再拉取所有获准事件的完整子市场历史。只有整轮通过校验且公开内容发生变化时，才提交新的数据版本并触发 Pages 构建；任一步失败都会保留上一版。Jev 待核与人工排除事件不会自动发布。

网页为静态 HTML、CSS、JavaScript 和 JSON；页面每次加载时读取已发布的快照，不代表实时行情。市场概率与走势的来源时间以各市场文件及页面标注为准。
